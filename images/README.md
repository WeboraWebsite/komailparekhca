# Images Directory

## Required Logo File

**IMPORTANT**: Please add the company logo file as `logo.png` in this directory.

### Specifications:
- **Filename**: `logo.png` (or update the HTML files if using a different format like .svg or .jpg)
- **Recommended dimensions**: 
  - Height: 100-150px (will be scaled to 50px on desktop, 40px on tablet, 35px on mobile)
  - Width: Proportional to height, max 500px
  - Format: PNG with transparent background (recommended) or SVG
- **Location**: `/images/logo.png`
